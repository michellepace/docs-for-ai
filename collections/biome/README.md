**What is Biome?**

Biome is a fast, unified toolchain for formatting and linting JavaScript, TypeScript, JSX, JSON, CSS, HTML, and other web languages. A single command-line tool formats code, enforces code quality rules, and organises imports, replacing separate tools like ESLint and Prettier. Biome integrates with popular editors, continuous integration systems, and git workflows, offering zero-configuration setup with optional customisation through a simple configuration file.
