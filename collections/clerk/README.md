**What is Clerk?** A user authentication and management platform for modern web applications. It provides prebuilt UI components, session management, and organisation features that drop into frameworks like Next.js, covering sign-in flows, multi-factor authentication, user profiles, and role-based permissions. Sessions combine short-lived JWT tokens with stateful server-side sessions, refreshed automatically to keep apps both fast and secure.
