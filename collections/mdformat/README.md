**What is mdformat?** An opinionated Markdown formatter that you can run from the command line, from Python, or as a pre-commit hook. It rewrites Markdown in one consistent style without changing how the document renders. Plugins add support for extra syntax, such as GitHub Flavored Markdown, and can also format code blocks.
