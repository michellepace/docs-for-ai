**What is shadcn?**

shadcn/ui is a collection of beautifully designed, accessible components built with TypeScript, Tailwind CSS, and Radix UI primitives. Unlike a traditional component library, the CLI copies the component source code directly into your project, so you own and customise it freely — no locked-up npm dependency. Theming is handled through CSS variables and design tokens, and it works across frameworks including Next.js, Vite, Remix, Astro, and Laravel. Its registry system lets you publish and distribute your own components, hooks, and config the same way.
