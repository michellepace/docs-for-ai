**What is shadcn?** A collection of accessible, well-designed React components built with TypeScript, Tailwind CSS, and Radix UI. Rather than installing a component library, you use its CLI to copy the source code into your project, so you own and customise it freely. Theming is handled with CSS variables, and it works across frameworks including Next.js, Vite, Remix, Astro, and Laravel.
