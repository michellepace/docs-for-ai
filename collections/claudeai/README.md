# Claude.ai Documentation

Curated docs for targeted AI context.

- Curation Index: [INDEX.xml](INDEX.xml)
- Curation Source: https://claude.com/docs/

**What is Claude.ai?** Anthropic's Claude product and the ways you extend and deploy it — not the developer API. These docs cover connectors, the MCP servers that give Claude your tools and data, plus the directory they ship through; skills and plugins that teach Claude your way of working; Cowork, where you hand Claude a goal and check back; and Claude inside Slack (Claude Tag), Microsoft 365, Science, third-party platforms and Government. Sibling collections: [`claudecode/`](../claudecode/) for the coding agent, [`claudeplat/`](../claudeplat/) for the developer platform.
