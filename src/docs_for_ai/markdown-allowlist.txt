# URL prefixes whose pages have a plain .md twin (page URL + ".md").
# Curating any URL under a prefix here fetches that .md instead of scraping the page.
#
# Example: with the "https://clerk.com/docs/" prefix below,
#   /curate-doc clerk https://clerk.com/docs/guides/ai/skills
#   → fetches .md twin https://clerk.com/docs/guides/ai/skills.md directly
