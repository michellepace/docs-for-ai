**What is Biome?** A fast Rust toolchain for web projects. One package (`@biomejs/biome`) and one `biome.json` give you a formatter, linter and assists like import sorting. The formatter is Prettier-compatible. Lint rules are ported from ESLint and its plugins. It formats ~25× faster than Prettier and lints ~15× faster than ESLint. It works on malformed code as you type and ships a language server.
