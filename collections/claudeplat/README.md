**What is Claude Platform?** Anthropic's developer platform for calling Claude from your own code. Two ways to build: the Messages API, where you own the loop, tool use and conversation state; or Managed Agents, stateful sessions Anthropic runs for you. Around them sit the model family, Agent Skills and MCP, prompt caching, evals and guardrails, the Console, admin and usage monitoring, and deployment via Bedrock, Google Cloud or Microsoft Foundry. Sibling collections: [`claudeai/`](../claudeai/) for the Claude.ai product, [`claudecode/`](../claudecode/) for the coding agent.
