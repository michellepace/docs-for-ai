**What is Tailwind?** A utility-first CSS framework for building custom user interfaces by composing small, single-purpose classes directly in your HTML markup. Rather than writing custom CSS, you apply pre-built utility classes like `flex`, `bg-blue-500`, and `hover:underline` to style elements, with support for responsive breakpoints, dark mode, and arbitrary values when needed.
