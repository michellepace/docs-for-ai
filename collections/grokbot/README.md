**What is Grok Bot?** xAI's AI agent that works like a teammate. Each Bot has its own memory and shares a persistent cloud computer (browser, files, terminal), so it can do real tasks across apps and websites while you're away. Connect Gmail, Slack, Drive or any MCP server, schedule routines, and let several Bots hand work to each other, checking with you before sensitive steps. Signs in with your Cursor account.
