**What is Rich?** A Python library for writing rich text and beautiful formatting to the terminal. Through its `Console` API it renders colour and style, tables, panels, progress bars, syntax-highlighted code, and Markdown, and it can pretty-print and inspect any Python object. Building blocks like `Layout` and `Live` compose into full-screen terminal dashboards that update in place.
