**What is ty?** Astral's Python type checker and language server, from the makers of uv and Ruff. `ty check` finds type errors from the command line, with a watch mode that rechecks only what changed. In your editor it adds live diagnostics, code navigation and completions. These docs cover setup, configuration, rules and how to suppress them, and what sets ty's type system apart.
