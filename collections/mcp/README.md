**What is MCP?** The Model Context Protocol is an open standard for connecting AI applications to outside systems — local files, databases, tools and prompt workflows. Think USB-C for AI: a server exposes its capabilities once, and any MCP client (Claude, ChatGPT, VS Code, Cursor) can use them, so an integration is built once rather than rebuilt per application.
