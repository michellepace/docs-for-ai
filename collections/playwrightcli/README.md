**What is playwrightcli?** A command-line interface for browser automation, built for coding agents (Claude Code, GitHub Copilot, etc.) that need token-efficient browser control without loading large tool schemas or verbose accessibility trees into context. It covers page interaction, element targeting, screenshots, network and storage management, and persistent sessions with a `show` dashboard for monitoring.
