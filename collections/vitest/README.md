**What is Vitest?** A next-generation testing framework powered by Vite, with a Jest-compatible API that works as a drop-in replacement in most projects. It reuses your app's Vite config, plugins and transform pipeline, so tests need no separate build setup. Test files run in parallel, isolated processes, and watch mode reruns only affected tests. Mocking, snapshots, coverage, benchmarking and type testing are built in.
