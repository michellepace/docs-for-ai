**What is Clerk?**

Clerk is a complete user authentication and management platform for modern web applications. It provides prebuilt UI components, session management, and organisation features that integrate with frameworks like Next.js, handling everything from sign-in flows and multi-factor authentication to user profiles and role-based permissions. Clerk uses a hybrid authentication model that combines the scalability of stateless JWT tokens with the security of stateful sessions, automatically refreshing short-lived tokens to maintain both performance and security.
