**What is Next.js?** A React framework for building full-stack web applications with file-system based routing, server-side rendering, and built-in optimisations. It provides automatic code splitting, image and font optimisation, and a powerful caching system that makes it simple to create fast, production-ready websites. Next.js supports both static and dynamic rendering, with features like Server Components, Server Actions, and streaming for modern interactive experiences.
