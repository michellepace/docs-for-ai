**What is coderabbit?** An AI code reviewer for pull requests on GitHub, GitLab, Bitbucket and Azure DevOps. It posts a walkthrough and line-by-line comments, learns your team's conventions from past reviews and files like `CLAUDE.md`, and offers fixes. The same reviews run locally over uncommitted Git changes via the `coderabbit` CLI, or inside Claude Code through its plugin.
