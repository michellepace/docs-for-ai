**What is Claude Code?**

Claude Code is Anthropic's agentic coding tool: Claude runs in your terminal (also as a desktop app, web app, and IDE extension), reads and edits files, runs shell commands, and works through tasks in an agentic loop under a permission system you control. It is customised through `CLAUDE.md` project instructions, skills, hooks, subagents, and MCP servers, and can run non-interactively with `claude -p` for scripts and CI.
